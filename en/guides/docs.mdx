## Introduction

A Doc is a document you write and edit together with your teammates, and with your agents, directly in Scalt. Each Doc lives in a space. It is either **private** (only you can see it) or **shared with the space** (everyone in the space can read it).

## Use as knowledge

A Doc shared with the space can also become part of the space's knowledge: your agents can then find it and quote it when they answer.

<Info>
  The **Use as knowledge** setting is set per Doc. It is **on by default** for every new Doc.
</Info>

### Who can change it

Only people who manage the Doc can turn the setting on or off: its owner, or an admin of the space for a Doc shared with the space.

### What is used

- Only Docs shared with the space are used. A private Doc is never used as knowledge, not even for its author.
- After you edit a Doc, allow about 2 minutes after the last change before it can be found. While someone keeps editing, it is refreshed at least every 10 minutes.

### When a Doc stops being used

A Doc disappears from search immediately when you:

- turn off **Use as knowledge**,
- make the Doc private,
- delete the Doc.

### Who can use it

Any agent working in the space without source subscriptions reads the Doc: the Scalter, assistants, and also the space's channels, API keys and Apps. Assistants and Apps that work from specific subscriptions do not read it.

### Citations

When an answer quotes a Doc, clicking the citation opens it, as long as you have access to that Doc.
