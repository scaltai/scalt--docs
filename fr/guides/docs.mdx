## Introduction

Un Doc est un document que vous rédigez et modifiez avec vos collègues, et avec vos agents, directement dans Scalt. Chaque Doc vit dans un space. Il est soit **privé** (vous seul le voyez), soit **partagé avec le space** (tout le space peut le lire).

## Utiliser comme connaissance

Un Doc partagé avec le space peut aussi entrer dans la connaissance du space : vos agents peuvent alors le retrouver et le citer dans leurs réponses.

<Info>
  Le réglage **Utiliser comme connaissance** se fait doc par doc. Il est **activé par défaut** pour chaque nouveau Doc.
</Info>

### Qui peut le modifier

Seules les personnes qui gèrent le Doc peuvent activer ou désactiver ce réglage : son propriétaire, ou un administrateur du space pour un Doc partagé avec le space.

### Ce qui est utilisé

- Seuls les Docs partagés avec le space sont utilisés. Un Doc privé n'est jamais utilisé comme connaissance, même pour son auteur.
- Après une modification, comptez environ 2 minutes après le dernier changement avant que le Doc puisse être retrouvé. Pendant une édition continue, il est mis à jour au moins toutes les 10 minutes.

### Quand un Doc n'est plus utilisé

Un Doc disparaît immédiatement de la recherche quand vous :

- désactivez **Utiliser comme connaissance**,
- passez le Doc en privé,
- supprimez le Doc.

### Qui peut l'utiliser

Le Doc est lu par les canaux, les clés API et les Apps du space qui n'ont pas d'abonnements à des sources. Les assistants et Apps qui travaillent à partir d'abonnements précis ne le lisent pas.

### Citations

Quand une réponse cite un Doc, cliquer sur la citation l'ouvre, si vous avez accès à ce Doc.
