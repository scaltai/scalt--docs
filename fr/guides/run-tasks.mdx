## Orchestration d'agents

Quand une demande comporte plusieurs parties indépendantes, un assistant peut les confier à des sous-agents qui travaillent en parallèle, puis réunir leurs résultats en une seule réponse. Chaque délégation apparaît dans le fil d'activité de la conversation (« Delegated to … »). Si les contrôles de sécurité de Scalt arrêtent un sous-agent, toute la réponse s'arrête.

### Qu'est-ce que l'orchestration d'agents ?

L'**orchestration d'agents** vous permet de créer des **équipes d'agents** qui collaborent pour accomplir des tâches complexes. Chaque agent a son rôle spécialisé, et ensemble ils forment un système intelligent et coordonné.

</Info>

### Pourquoi l'orchestration ?

<Tabs>
  <Tab title="Tâches complexes">
    Certaines tâches nécessitent plusieurs compétences :
    
    **Exemple : Lancement de produit**
    - **Agent Marketing** : Crée le contenu et les visuels
    - **Agent Social Media** : Planifie les publications
    - **Agent Analytics** : Suit les performances
    - **Agent CRM** : Met à jour les segments clients
    - **Orchestrateur** : Coordonne le tout
  </Tab>
  
  <Tab title="Spécialisation">
    Chaque agent excelle dans son domaine :
    
    - **Agent Rédacteur** : Copywriting optimisé
    - **Agent Traducteur** : Multilingue natif
    - **Agent SEO** : Optimisation pour les moteurs
    - **Agent Designer** : Génération d'images
    
    Ensemble, ils produisent du contenu de qualité supérieure.
  </Tab>
  
  <Tab title="Scalabilité">
    Adaptez le nombre d'agents selon la charge :
    
    - **Traffic normal** : 1 agent de support
    - **Pic d'activité** : 5 agents en parallèle
    - **Automatique** : Scale up/down selon le besoin
  </Tab>
</Tabs>

### Planification personnalisée (Cron)

Pour des besoins spécifiques, utilisez la syntaxe cron :

<CodeGroup>

```cron Exemples de syntaxe cron
# Format : minute heure jour mois jour_semaine

# Tous les jours ouvrés à 9h00
0 9 * * 1-5

# Tous les lundis et mercredis à 14h30
30 14 * * 1,3

# Le 1er et le 15 de chaque mois à 8h00
0 8 1,15 * *

# Toutes les 15 minutes
*/15 * * * *

# Tous les jours à 9h, 12h et 18h
0 9,12,18 * * *

# Le dernier jour de chaque mois à minuit
0 0 28-31 * *
```

```yaml Configuration complète
schedule:
  name: "Rapport hebdomadaire"
  cron: "0 9 * * 1"  # Tous les lundis à 9h
  timezone: "Europe/Paris"
  enabled: true
  
  # Paramètres optionnels
  params:
    date_range: "last_7_days"
    format: "pdf"
  
  # Notifications
  notifications:
    on_start:
      - type: "slack"
        channel: "#notifications"
        message: "🚀 Génération du rapport hebdomadaire..."
    
    on_success:
      - type: "email"
        to: ["equipe@entreprise.com"]
        subject: "Rapport hebdomadaire disponible"
        attach_output: true
    
    on_failure:
      - type: "slack"
        channel: "#alerts"
        message: "❌ Échec de la génération du rapport"
        mention: ["@admin"]
```

</CodeGroup>

<Tip>
  **Outil de test** : Utilisez [crontab.guru](https://crontab.guru/) pour vérifier votre syntaxe cron et visualiser les prochaines exécutions.
</Tip>

## Exécutions déclenchées par événement

Au-delà de la planification temporelle, vos agents peuvent être déclenchés par des événements.

### Webhooks

Déclenchez votre agent depuis une application externe :

<CodeGroup>

```bash cURL
curl -X POST https://app.scalt.ai/api/webhook/your-agent-id \
  -H "Authorization: Bearer YOUR_WEBHOOK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_email": "client@example.com",
    "order_id": "ORD-12345",
    "amount": 299.99
  }'
```

```javascript JavaScript
const response = await fetch('https://app.scalt.ai/api/webhook/your-agent-id', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_WEBHOOK_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customer_email: 'client@example.com',
    order_id: 'ORD-12345',
    amount: 299.99
  })
});

const result = await response.json();
console.log('Agent exécuté :', result.execution_id);
```

```python Python
import requests

url = "https://app.scalt.ai/api/webhook/your-agent-id"
headers = {
    "Authorization": "Bearer YOUR_WEBHOOK_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "customer_email": "client@example.com",
    "order_id": "ORD-12345",
    "amount": 299.99
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(f"Agent exécuté : {result['execution_id']}")
```

</CodeGroup>

### Définir les priorités

```yaml Configuration des priorités
queue:
  strategy: "priority"  # fifo, priority, parallel
  
  priority_rules:
    - condition: ${input.customer_tier} == "vip"
      priority: 1  # Plus haut = plus prioritaire
    
    - condition: ${input.amount} > 10000
      priority: 2
    
    - default_priority: 5
  
  concurrency:
    max_parallel: 3  # Maximum 3 exécutions simultanées
    per_minute: 10   # Maximum 10 exécutions par minute
```
